# NUR2460 Family Nursing Care Study Hub

Static Fall 2026 study hub with:

- 42 stable Study Tool topics
- 67 imported Pharmacology records
- 275 stable Flashcards
- A four-exam course map aligned to the supplied schedule and instructor-note set

Open `index.html` locally or serve this directory with any static web server.

## Content status

Course scope has been aligned to the Fall 2026 syllabus, schedule, 24 instructor-note documents, and reproductive/OB medication handout. Existing clinical prose is still an imported draft under claim-level audit. ATI/SUPP/Both badges identify legacy attribution and must not be treated as completed verification.

Instructor documents, copied graphics, and question screenshots are intentionally not included in this public repository.

See `STUDY_TOOL_UPDATE_REPORT.md` for source authority, coverage, conflicts, learner-state preservation, medication dispositions, and QA status.

## Publishing workflow

Use a review branch such as `codex/fall-2026-alignment`, verify the static pages, then merge into the repository's GitHub Pages branch only after review. Do not overwrite the live site directly from an unrelated local repository.
